# Opt-in agent directory

`apps/registry/data/deployments.json` lists documented Jev Traps integrations. Empty means **no documented deployments**, not zero worldwide users. There is no tracking, identity inference or automated claim that an authenticated ingest key represents a particular agent.

To request a listing, open a PR adding an entry with `name`, an HTTPS `url` pointing to public integration evidence, a short factual `description` and `verifiedAt` (YYYY-MM-DD). Include the owner's explicit agreement to a public listing and the code/reference showing Jev Traps use. Never add private endpoint names, customer identities or ingest credentials. A maintainer checks the reference and date before merging.

Anthropic/OpenAI/open-weight compatibility describes integration options, not adoption. The ecosystem cards link to independent Jev projects: [jev-mcp](https://github.com/burnigtm/jev-mcp), [pi-heed](https://github.com/Nyarlathoteppppp/pi-heed), and [tax-doc-classifier](https://github.com/kyotofin/tax-doc-classifier). Their inclusion does not claim they use Jev Traps or endorse this project. Performance results from their own workloads must not be advertised as Jev Traps benchmarks.
